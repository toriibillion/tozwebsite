# 🌐 Toez Website

مرحبًا بك في الموقع الرسمي لفريق **Toez**، حيث يلتقي عشاق ألعاب الفيديو لقضاء أجمل الأوقات في عالم الألعاب! 🎮🔥

## 📋 محتويات الموقع

- 🎬 **الصفحة الرئيسية (Start)** — ترحيب أنيق وواجهة أنيميشن جذابة.
- ℹ️ **من نحن** — تعريف مختصر بفريق Toez وأهدافه.
- 📜 **قوانين** — قواعد وأخلاقيات التعامل داخل الفريق.
- 💬 **الديسكورد** — رابط مباشر للانضمام إلى سيرفر Discord الخاص بنا.

## 🚀 المميزات

- تصميم متجاوب بالكامل (Responsive)
- تأثيرات انتقال سلسة بين الأقسام
- حماية من أدوات المطور (Developer Tools Detection)
- استخدام أيقونات Font Awesome وأسلوب عصري في التصميم
- مبني باستخدام **HTML + CSS + JavaScript**

## 🛠️ التقنيات المستخدمة

- HTML5
- CSS3 (Tailwind + Custom Styles)
- JavaScript (للتفاعلات والحماية)
- Font Awesome
- Particles.js (للتأثيرات البصرية)
